            Install the BuzzTorrent app on Google TV
            1. On the TV, install Downloader (by AFTVnews) from the Play Store.
            2. TV Settings → Apps → Security & restrictions → Unknown sources → allow Downloader.
            3. In Downloader, type http://…/BuzzTorrentTV.apk and choose Install.

            Or with a pen drive: run python android\build_apk.py --usb with the pen drive plugged in, plug it into the TV, and open BuzzTorrentTV-….apk with a file manager app (e.g. File Commander or X-plore from the Play Store; allow it under Unknown sources).
